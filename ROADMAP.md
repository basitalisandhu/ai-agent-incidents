# Roadmap

This is what we are working on and what we would like help with, in plain order. It is a list of intentions, not promises: there are no dates, and the order changes when people show up or the evidence changes. Every item links an issue. Comment there to claim it or to argue for a different order, or vote in the [Roadmap discussion](https://github.com/basitalisandhu/ai-agent-incidents/discussions).

## Now

- [#20](https://github.com/basitalisandhu/ai-agent-incidents/issues/20): Check the OWASP Agentic Top 10 mappings against the published document
- [#6](https://github.com/basitalisandhu/ai-agent-incidents/issues/6): Add archived copies for sources the build network could not reach

## Next

- [#3](https://github.com/basitalisandhu/ai-agent-incidents/issues/3): Add an issue form for corrections
- [#4](https://github.com/basitalisandhu/ai-agent-incidents/issues/4): Add a JSON Lines export
- [#7](https://github.com/basitalisandhu/ai-agent-incidents/issues/7): Add a "Cite this record" block to every event page
- [#21](https://github.com/basitalisandhu/ai-agent-incidents/issues/21): Publish a monthly digest of new incidents

## Later

- [#19](https://github.com/basitalisandhu/ai-agent-incidents/issues/19): Add a controls field: what would have stopped each event

## Not planned

- Records of unpublished vulnerabilities. Report to the vendor first; a record needs a public source.
- Opinion or blame. Records state what the sources say.

Want to add something? Open an issue describing the problem first, with what done looks like. The [CONTRIBUTING.md](CONTRIBUTING.md) file explains the rest.
